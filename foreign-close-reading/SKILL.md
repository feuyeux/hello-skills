# 外语原著逐句精读

产出物：一个单文件交互式 HTML 阅读器。正文连续排版如纸质书，点击任意句子，讲解卡片就地展开（翻译 → 🔤 生词 → 🧩 语法 → 🌍 文化），←/→ 键逐句往下读，阅读进度自动保存在浏览器。用户不需要学任何操作。

## 工作流程

### 1. 确定文本与范围

- 输入须是纯文本（.txt / .md）。若是 epub/pdf/docx，先用 pandoc（`pandoc -t plain`）等工具提取正文，删掉版权页、目录、译本序等非正文噪音。
- 讲解语言默认中文；若用户指定其他语言则遵循。
- 范围：短文本全量处理。长文本默认取开头 30–60 句（或用户指定的章节），明确告知用户本次覆盖第 1–N 句，之后用户说"继续"即可用 `--start N+1` 增量生成下一批，合并进同一个 data.json。

### 2. 切分句子

```bash
python3 scripts/split_sentences.py INPUT.txt [--start N] [--limit N] --out sentences.json
```

输出 `{"lang":"latin"|"cjk","total":M,"sentences":[{"id","text","para"}]}`。id 全局连续从 1 起，para 是自然段编号（阅读器据此还原排版）。切分脚本处理了缩写（Mr./e.g.）、小数（3.14）、CJK 结尾引号等情况，不要自己手写切分逻辑。

### 3. 逐句生成讲解（核心步骤，质量决定一切）

把 sentences.json 逐句扩充为 `data.json`（schema 与示例见下）。长文分批生成，每批 10–15 句，每批完成后立即写入文件，避免中途丢失。

**翻译**：地道的文学翻译，保留原文的语气与语域；不逐字硬译。

**生词**：只挑中高级学习者真正会卡住的词与搭配（CEFR B1 以上），the / very / house 这类不要出现。优先收：惯用语、固定搭配、文化负载词、一词多义的罕见义项。英文给 IPA 音标，日文给假名读音（`p` 字段）。释义精准；当用法、语域或与常见义的差异不显然时，加一句 `n` note。

**语法**：解析**这一句本身**的结构，不要写成通用语法教科书。先点出句子骨架（主干/主谓宾），再讲值得注意的构造——从句嵌套、倒装、虚拟、省略、非谓语、时体选择、古雅用法等——引用句中片段说明作者为什么这么写（强调？反讽？正式？）。简单句若无值得讲的就少讲，不要凑条目。

**文化**：只在句子确有文化分量时写——典故出处、历史背景、双关与幽默、社会习俗、宗教/品牌/地名的言外之意。紧扣句中词语展开，写成有信息量的小故事，不空谈背景。**绝不硬编；没有就整个省略 culture 字段。**这一项是本 skill 区别于普通注释器的价值所在，但宁缺毋滥。

任何不确定的事实都不要编造。

### 4. 生成阅读器

```bash
python3 scripts/build_reader.py --data data.json --out "<书名>-精读.html"
```

模板自动取自 `assets/reader_template.html`，无需手动改模板。

### 5. 交付

把 HTML 文件路径作为链接交给用户，附一句话说明："浏览器打开，点任意句子看讲解，←/→ 逐句往下读。"不要长篇解释操作。

## data.json schema

```json
{
  "title": "Pride and Prejudice · Chapter 1",
  "subtitle": "Jane Austen",
  "lang": "latin",
  "sentences": [
    {
      "id": 1,
      "text": "It is a truth universally acknowledged, that a single man in possession of a good fortune, must be in want of a wife.",
      "para": 1,
      "translation": "凡是有钱的单身汉，总想娶位太太，这已经成了一条举世公认的真理。",
      "words": [
        {"w": "in possession of", "p": "", "m": "拥有，持有（正式、带法律味）"},
        {"w": "be in want of", "m": "缺乏，需要（古雅）", "n": "want 作名词的旧式用法；奥斯汀用这种煞有介事的正式腔调开篇，为全句的反讽定调"}
      ],
      "grammar": [
        {"t": "无人称的“真理”句式", "d": "It is a truth universally acknowledged that… 把一个观点包装成举世真理，掩盖了是谁在主张它——反讽正藏在这个被动结构里"},
        {"t": "插入语分隔主谓", "d": "a single man … must be 之间塞进 in possession of a good fortune，拉长的节奏模仿当时劝世文的装腔作势"}
      ],
      "culture": [
        {"t": "英语文学最著名的开场白之一", "d": "奥斯汀故意模仿当时布道文与行为手册的口吻，把婚姻这门“生意”说成天经地义，一句道破全书的主题：在限定继承法之下，没有财产的女性把婚姻当作唯一的出路。"}
      ]
    }
  ]
}
```

- `title` 必填；`subtitle`、`lang` 可省。`lang` 为 `"cjk"` 时阅读器不加句间空格。
- 每句必填 `id` / `text` / `para` / `translation`；`words` / `grammar` / `culture` 数组及其内的 `p` / `n` / `t` 字段按内容省略。
- 上一例同时也是讲解质量的样板：语法扣这一句的写法，文化讲成有出处、有观点的故事。
